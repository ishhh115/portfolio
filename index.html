BankOS

Concurrent Banking Transaction System  ·  C, POSIX Threads, Linux

POSIX Threads Mutex + Lock Ordering Banker's Algorithm Semaphore Throttling

Multi-threaded banking system in C implementing mutex locks with lock-ordering protocol, reader-writer locks for read-heavy access, and semaphore-based teller throttling — 5 resource-bounded tellers servicing 20+ concurrent customers across 10 accounts with a 100-slot transaction queue. Deadlock prevention via ordered lock acquisition; Banker's Algorithm validates safe resource allocation across 10 threads and 3 resource types.

Key Features

  • Mutex locks with ordered lock acquisition preventing race conditions and ensuring 100% atomic transaction consistency during concurrent operations
  • Producer-consumer transaction pipeline using circular buffers, condition variables, and real-time dashboard with live queue monitoring
  • Banker's Algorithm implementation detecting safe states across 10 threads and 3 resource types, computing safe execution sequences during bidirectional fund transfers

Technical Achievements

  • Implemented mutex locks with ordered lock-acquisition protocol eliminating race conditions and ensuring atomic transactions across concurrent account operations
  • Designed semaphore-based teller throttling system managing bounded resource pool (5 tellers) from 20+ concurrent customer threads using counting semaphores
  • Engineered producer-consumer pipeline using circular buffers and pthread condition variables for thread synchronization and bounded queue management
  • Integrated Banker's Algorithm for resource allocation safety validation across 10 threads and 3 resource types, computing safe execution sequences and preventing deadlocked states
  • Built real-time interactive dashboard with color-coded balance visualization, active thread tracking, and live transaction queue monitoring
